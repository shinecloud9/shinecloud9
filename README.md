### 📄 Publication

**Not as Sweet by Another Name: An Empirical Study of Format Robustness in LLM Document Workflows**<br>
Xiaoyu Zhang, **Xianyun Cheng**, Tianlin Li, Yuwei Zheng, Yue Yang, Yang Liu<br>
*ASE 2026, the 41st IEEE/ACM International Conference on Automated Software Engineering* (Munich)

A format-aware metamorphic testing framework for LLM document workflows. Across 48,000 executions, simply
changing the file format (TXT / JSON / CSV / PDF) cut accuracy by up to 53.63% and flipped decisions in over 41%
of cases. Lightweight test-time safeguards recovered up to 44.21% of the drift without retraining.
